# Документация по проекту B1Void Inspector App

## 1. Обзор проекта

### 1.1. Общее описание

**B1Void Inspector App** - это Android-приложение, предназначенное для проведения инспекций. Оно сочетает в себе файловый менеджер для организации фотографий, функционал камеры для создания снимков и возможность синхронизации данных с облачными сервисами. Приложение разработано для профессионального использования и оптимизировано для работы на устройствах с ограниченными ресурсами.

### 1.2. Ключевые особенности

- **Продвинутая камера:** Расширенные настройки камеры, включая управление экспозицией, разрешением и форматом изображения.
- **Файловый менеджер:** Управление файлами и папками, включая создание, переименование, удаление и перемещение.
- **Создание инспекций:** Возможность создавать инспекции и привязывать к ним фотографии.
- **Синхронизация с Dropbox:** Загрузка файлов в облачное хранилище Dropbox.
- **Редактирование изображений:** Базовые возможности редактирования, включая изменение качества изображения.

## 2. Архитектура и технологический стек

### 2.1. Технологический стек

- **Языки программирования:** Kotlin и Java
- **Платформа:** Android
- **Система сборки:** Gradle с Kotlin DSL
- **Камера:** CameraX и CameraView
- **Облачные сервисы:** Dropbox API

### 2.2. Структура проекта

```
com.example.b1void/
├── activities/          # Экраны приложения
├── adapters/           # Адаптеры для списков
├── models/             # Модели данных
├── tasks/              # Асинхронные задачи для Dropbox
└── utils/              # Вспомогательные классы
```

## 3. Основные компоненты

### 3.1. Activities

- **`FileManagerActivity.kt`**: Основной экран файлового менеджера. Отвечает за отображение файлов и папок, навигацию по директориям и запуск других активностей (камера, создание инспекции).
- **`CameraV2Activity.java`**: Экран камеры с расширенными настройками. Позволяет делать снимки, настраивать параметры камеры и сохранять изображения в указанную директорию.
- **`InspectionAddActivity.java`**: Экран создания новой инспекции. Позволяет делать фотографии, которые привязываются к создаваемой инспекции.
- **`ImagePreviewActivity.kt`**: Экран для полноэкранного просмотра изображений.
- **`EditImageActivity.java`**: Экран для редактирования изображений.
- **`SplashActivity.java`**: Загрузочный экран приложения.
- **`NavigationApp.kt`**: Навигационный хаб приложения.
- **`AdmActivity.kt`**: Административная панель.
- **`ShowInspectionActivity.kt`**: Экран просмотра деталей инспекции.
- **`WorkerActivity.java`**: Экран для исполнителей.
- **`AdmLogActivity.java`**: Экран для просмотра логов.

### 3.2. Adapters

- **`FileAdapter.kt`**: Адаптер для отображения списка файлов и папок в `FileManagerActivity`.

### 3.3. Utils

- **`FileManagerUtils.kt`**: Утилиты для работы с файлами и директориями.

### 3.4. Models

- В проекте отсутствуют явные модели данных в виде классов, но подразумевается работа с сущностями "Инспекция" и "Файл".

### 3.5. Dropbox Tasks

- **`UploadTask.kt`**: Задача для загрузки файлов в Dropbox.

## 4. Файлы конфигурации

### 4.1. `build.gradle.kts`

- **`app/build.gradle.kts`**: Основной конфигурационный файл модуля приложения. Содержит зависимости, настройки сборки и параметры приложения.

### 4.2. `AndroidManifest.xml`

- Манифест приложения, в котором объявлены все активности, разрешения и другие компоненты.

## 5. Рекомендации по разработке

### 5.1. Приоритетные улучшения

- **Внедрение MVVM:** Разделить логику представления и бизнес-логику с помощью ViewModel для улучшения тестируемости и поддерживаемости кода.
- **Расширение тестового покрытия:** Добавить Unit-тесты и UI-тесты для обеспечения стабильности приложения.
- **Рефакторинг `CameraV2Activity`:** Разбить большой класс `CameraV2Activity` на более мелкие и переиспользуемые компоненты.
- **Миграция на Kotlin:** Постепенно переводить оставшиеся Java-классы на Kotlin.

### 5.2. Технический долг

- **Удаление `CameraActivity.kt`:** Файл старой камеры все еще присутствует в проекте и должен быть удален.
- **Отсутствие моделей данных:** Создать классы моделей для инспекций и других сущностей для более строгой типизации и удобства работы с данными.
- **Прямые вызовы `startActivity`:** Заменить прямые вызовы `startActivity` на более современный подход с использованием Navigation Component.
