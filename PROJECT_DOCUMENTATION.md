# Проектная документация: Inspector App

## 1. Обзор проекта

**Назначение:** Мобильное Android-приложение для проведения инспекций товаров на складах сети "Магнит".

**Основная концепция:** Приложение функционирует как файловый менеджер для фото и видео, сделанных в ходе инспекций. Оно позволяет пользователям создавать инспекции, прикреплять к ним медиафайлы, сделанные с помощью камеры устройства или добавленные из галереи, управлять этими файлами и выгружать их в облачные хранилища.

## 2. Техническое описание

### 2.1. Стек технологий

*   **Язык программирования:** Kotlin
*   **Архитектура:** MVVM (Model-View-ViewModel)
*   **Сборка:** Gradle с использованием Kotlin DSL
*   **Минимальная версия Android:** API 25 (Android 7.1 Nougat)
*   **Целевая версия Android:** API 34 (Android 14)

### 2.2. Ключевые библиотеки и фреймворки

*   **UI:**
    *   AndroidX AppCompat, Material Components, ConstraintLayout
    *   ViewBinding для привязки представлений
*   **Работа с камерой:**
    *   **CameraX (`androidx.camera`):** Основная библиотека для работы с камерой.
*   **Работа с медиа:**
    *   **Glide:** Для эффективной загрузки и кэширования изображений и миниатюр видео.
    *   **Picasso:** Альтернативная библиотека для загрузки изображений.
*   **Асинхронные операции:**
    *   **Kotlin Coroutines:** Для управления фоновыми потоками и асинхронными задачами.
    *   **WorkManager:** Для выполнения отложенных фоновых задач.
*   **Хранение данных и бэкенд:**
    *   **Firebase:**
        *   **Authentication:** Для аутентификации пользователей.
        *   **Realtime Database:** Для хранения структурированных данных инспекций.
        *   **Cloud Storage:** Для хранения сделанных фотографий и видео.
    *   **Dropbox SDK:** Для интеграции и выгрузки файлов в Dropbox.
*   **Локальное хранение:**
    *   **DataStore Preferences:** Для хранения простых данных (настройки, токены).
*   **Прочее:**
    *   **MultiDex:** Для поддержки устройств с версией Android до API 21.

## 3. Архитектура приложения

Проект имеет многомодульную структуру, разделенную по функциональному назначению:

*   `com.example.b1void`
    *   `activities`: **(View)** Экраны приложения (Activity/Fragment).
    *   `adapters`: Адаптеры для `RecyclerView` для отображения списков.
    *   `ui`: Компоненты UI, такие как `BottomSheetDialogFragment`.
    *   `data`: Репозитории, источники данных и менеджеры настроек (`CameraSettingsManager`).
    *   `models`: Классы данных (data classes).
    *   `utils`: Общие вспомогательные утилиты.
    *   `workers`: Реализации `Worker` для WorkManager.
    *   `B1VoidApplication.kt`: Кастомный класс Application для инициализации библиотек.

## 4. Основные компоненты и экраны (Activities)

*   `SplashActivity`: Стартовый экран, точка входа в приложение.
*   `MainActivity`: Главный экран после входа.
*   `CameraActivity`: Основной экран для фото- и видеосъемки.
*   `FileManagerActivity`: Экран для просмотра и управления файлами.
*   `InspectionAddActivity`: Экран создания новой инспекции.
*   `ShowInspectionActivity`: Экран просмотра деталей существующей инспекции.
*   `ImagePreviewActivity`: Экран предпросмотра сделанной фотографии.
*   `EditImageActivity`: Экран для редактирования изображения.

## 5. Разрешения (Permissions)

Приложение запрашивает следующие разрешения:

*   `CAMERA`: Для фотосъемки.
*   `RECORD_AUDIO`: Для записи звука при видеосъемке.
*   `READ_EXTERNAL_STORAGE` (до API 32): Для чтения файлов из галереи/памяти устройства.
*   `READ_MEDIA_VIDEO` (с API 33): Для чтения видеофайлов из галереи.
*   `WRITE_EXTERNAL_STORAGE`: Для сохранения файлов (может требоваться для старых версий API).
*   `INTERNET` / `ACCESS_NETWORK_STATE`: Для взаимодействия с облачными сервисами.

## 6. Обновления и новый функционал (Август 2025)

### 6.1. Поддержка видео
- **Запись видео:** В режиме камеры добавлена возможность записи видео.
- **Импорт видео:** Реализован импорт видеофайлов из галереи устройства.
- **Отображение:** В файловом менеджере для видеофайлов отображаются миниатюры и иконка воспроизведения.
- **Воспроизведение:** При нажатии на видеофайл запускается системный видеоплеер.

### 6.2. Полная переработка интерфейса камеры (`CameraActivity`)
- **Переключатель режимов:** Вместо группы кнопок добавлен единый переключатель между режимами фото и видео.
- **Индикатор записи:** Кнопка съемки меняет свой вид на красный круг во время записи видео.
- **Миниатюра предпросмотра:** На экране камеры теперь отображается миниатюра последнего сделанного фото или видео. Нажатие на нее открывает экран предпросмотра (`ImagePreviewActivity`) для фото или системный плеер для видео.
- **Удаление устаревшего кода:** Полностью удалена активность `CameraV2Activity` и связанные с ней макеты для устранения путаницы и дублирования кода.

### 6.3. Меню настроек камеры
По нажатию на иконку настроек на экране камеры открывается всплывающее меню со следующими опциями:
- **Управление вспышкой:** Позволяет выбрать режим работы вспышки для фото (Авто / Включена / Выключена).
- **Штамп времени и даты:**
    - Позволяет включить или выключить автоматическое наложение текущей даты и времени на сделанные фотографии.
    - По умолчанию опция включена.
    - Штамп наносится в правый нижний угол фотографии красным цветом.
- **Выбор разрешения:**
    - Позволяет выбрать разрешение для фото из списка, поддерживаемого камерой устройства.
    - Выбранное разрешение сохраняется и используется для последующих снимков.
    - В списке текущее выбранное разрешение помечается галочкой.

### 6.4. Технические улучшения
- **Сохранение настроек:** Все настройки камеры (вспышка, штамп, разрешение) сохраняются между сессиями с использованием `DataStore Preferences`.
- **Получение разрешений:** Для получения списка доступных разрешений используется `Camera2CameraInfo` API.
- **Обработка изображений:** Для наложения штампа времени реализована обработка `Bitmap` с использованием `Canvas`.

## 7. Сборка и запуск

### Сборка APK
Для сборки отладочной версии приложения (debug APK) выполнить команду в корне проекта:
```bash
./gradlew assembleDebug
```

### Запуск на устройстве/эмуляторе
Открыть проект в Android Studio и запустить на выбранном устройстве.
