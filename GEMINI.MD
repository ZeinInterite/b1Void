# Роль
Ты профессиональный Android разработчик в проекте по созданию приложения для инспекции товаров на складе сети магнит. Приложение это файловый менеджер для хранения фотографий с функцией фотосъемки и синхронизации данных с облачными сервисами.

Твоя цель разрабытаывать и тестировать андроид приложением

 # Документация проекта:


## Общее описание проекта

**B1Void Inspector App** - это Android-приложение для проведения инспекций с возможностью фотосъемки, управления файлами и синхронизации данных с облачными сервисами. Приложение оптимизировано для работы на слабых устройствах и предназначено для профессионального использования в сфере инспекций и контроля качества.

### Основные возможности:
- 📷 Профессиональная фотосъемка с расширенными настройками камеры
- 📁 Встроенный файловый менеджер с поддержкой различных форматов
- ☁️ Синхронизация с Dropbox и Firebase
- 🔧 Административная панель для управления инспекциями
- 🎨 Редактирование изображений с инструментами рисования
- 📊 Система отчетов и логирования
- 🔐 Система аутентификации пользователей

---

## Архитектура проекта

### Технический стек:
- **Язык программирования**: Kotlin + Java
- **Платформа**: Android (API 25-35)
- **Система сборки**: Gradle с Kotlin DSL
- **Архитектурный паттерн**: MVVM (Model-View-ViewModel)
- **Облачные сервисы**: Firebase, Dropbox API
- **Камера**: CameraX + CameraView
- **Изображения**: Glide для загрузки и кэширования

### Структура пакетов:
```
com.example.b1void/
├── activities/          # Экраны приложения
├── adapters/           # Адаптеры для списков и RecyclerView
├── cameraFun/          # Функциональность камеры
├── models/             # Модели данных
├── tasks/              # Асинхронные задачи для Dropbox
├── utils/              # Утилиты и вспомогательные классы
└── viewmodels/         # ViewModel для MVVM архитектуры
```

## 🏗️ Конфигурационные файлы

### `build.gradle.kts` (корневой)
**Назначение**: Основной файл конфигурации проекта
- Определяет версии плагинов Android и Kotlin
- Подключает Google Services для Firebase

### `app/build.gradle.kts`
**Назначение**: Конфигурация модуля приложения
- **Основные настройки**:
    - `applicationId`: com.example.b1void
    - `minSdk`: 25 (Android 7.1)
    - `targetSdk`: 34 (Android 14)
    - `compileSdk`: 35
- **Оптимизации**:
    - MultiDex поддержка для слабых устройств

**Назначение**: Манифест приложения с разрешениями и активностями
